# Plant Disease Detection System (Deep Learning + Organic Solutions)

A working implementation of the system described in *"Development of a Plant
Disease Detection System Using Deep Learning and Organic Solutions for
Sustainable Agriculture"* (ICCSAI 2025). It:

1. Trains a CNN (transfer learning on MobileNetV2, matching the paper's
   methodology) to classify plant leaf images as healthy or diseased.
2. Looks up a JSON database of **organic/natural remedies** (neem oil,
   garlic, turmeric, cow urine, etc.) for the detected disease.
3. Provides a Tkinter GUI so a farmer can upload a photo and instantly see
   the diagnosis + remedy, exactly as described in the paper's Fig. 2.

## 1. Project structure

```
plant_disease_project/
├── data/
│   ├── raw/                     # (you add) one folder per class, all images
│   ├── train/                   # auto-generated by split_dataset.py
│   ├── val/                     # auto-generated by split_dataset.py
│   └── organic_solutions.json   # remedy database (already included)
├── models/                      # trained model + class list saved here
├── src/
│   ├── config.py                # all paths & hyperparameters
│   ├── split_dataset.py         # 80/20 train/val split utility
│   ├── model.py                 # CNN architecture (transfer learning)
│   ├── train.py                 # training script
│   ├── predict.py               # CLI inference
│   └── gui_app.py               # Tkinter desktop app
└── requirements.txt
```

## 2. Setup

```bash
cd plant_disease_project
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 3. Get a dataset

This project expects an **ImageFolder-style** dataset: one sub-folder per
class, containing that class's images. The **PlantVillage dataset** (used by
Mohanty et al., cited in the paper) is the standard choice and is freely
available on Kaggle — search "PlantVillage Dataset" on kaggle.com. Download
it and arrange it like this:

```
data/raw/Tomato___healthy/img1.jpg
data/raw/Tomato___Septoria_leaf_spot/img2.jpg
data/raw/Potato___Late_blight/img3.jpg
...
```

> **Important:** the folder names must match (or you must edit) the keys in
> `data/organic_solutions.json` so each disease maps to the correct remedy.
> Any class not found in the JSON falls back to the `_default` entry.

Then split it into train/val:

```bash
python src/split_dataset.py
```

(If your data already comes pre-split, just place it directly into
`data/train/<class>/` and `data/val/<class>/` and skip this step.)

## 4. Train the model

```bash
python src/train.py
```

This reproduces the paper's training setup:
- Images resized to 224×224, pixel values scaled via the backbone's
  preprocessing function
- Data augmentation: rotation, flip, zoom, shear (to fight limited/imbalanced
  data, as the paper discusses)
- Adam optimizer + categorical cross-entropy loss
- Up to 10 epochs, with early stopping and a second fine-tuning pass on the
  backbone's top layers
- Reports accuracy, precision, and recall (the paper explicitly names these
  as metrics worth adding beyond plain accuracy)

Outputs:
- `models/plant_disease_model.keras` — the trained model
- `models/class_names.json` — ordered list of class labels
- `models/training_history.png` — accuracy/loss curves

## 5. Run predictions

CLI:
```bash
python src/predict.py path/to/leaf_photo.jpg
```

GUI (matches the paper's Fig. 2 interface):
```bash
python src/gui_app.py
```

## 6. Notes on faithfully extending this toward the paper

- **Mobile deployment**: convert the saved `.keras` model with
  `tf.lite.TFLiteConverter` to get a `.tflite` file for Android/iOS, as the
  paper's "Future Work" section suggests.
- **More metrics**: `train.py` already tracks precision/recall; add
  `sklearn.metrics.classification_report` on the validation set for a full
  per-class F1-score breakdown, which the paper flags as a limitation of its
  own evaluation.
- **Environmental data / drones / IoT**: these are paper's future-work ideas,
  not implemented here — they'd require additional sensor data pipelines
  beyond the scope of a single leaf-image classifier.

## Disclaimer

The organic remedies in `organic_solutions.json` are illustrative examples
drawn from common traditional/organic-farming practice, matching the style
described in the paper. Before field application at scale, verify dosages
and safety with a local agricultural extension officer.
